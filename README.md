# 📱 QR Code Generator

A simple Python-based QR Code Generator that allows users to create custom QR codes easily.

---

## 🚀 Features

* Generate QR codes from text or URLs
* Save QR codes as images
* Custom QR code generation support
* Easy to use Python scripts

---

## 🛠️ Technologies Used

* Python 🐍
* qrcode library
* PIL (Python Imaging Library)

---

## 📂 Project Structure

```
qrcode/
│── qr.py            # Basic QR code generator
│── qradv.py         # Advanced QR code generator
│── qruser.py        # User input based QR generator
│── qrcode.png       # Sample output
│── custom_qrcode.png
│── user_qrcode.png
```

---

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/GauriSinghRawat/qr-code-generator.git
```

2. Navigate to project folder:

```
cd qr-code-generator
```

3. Install required libraries:

```
pip install qrcode[pil]
```

---

## ▶️ Usage

Run any file:

```
python qr.py
```

OR

```
python qruser.py
```

👉 Follow instructions in terminal and your QR code will be generated.

---

## 📸 Output Example

QR codes will be saved as `.png` files in the project folder.
